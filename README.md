# ZenDigest

Автоматический русскоязычный культурный дайджест по кино, сериалам, книгам и музыке: сбор RSS, дедупликация, редакторский отбор через Gemini, SQLite и публикация отдельных новостей с фотографиями в Telegram.

## Ежедневный цикл

- 07:30 Europe/Moscow — сбор материалов, отбор до пяти значимых новостей и подготовка очереди.
- 08:00, 10:00, 12:00, 14:00 и 16:00 Europe/Moscow — публикация следующей новости.
- Каждый пост отправляется одним сообщением Telegram: фотография + подпись.
- Подпись автоматически ограничивается 1024 UTF-16 единицами Telegram API; ссылка на источник сохраняется.
- Для публикации используются только материалы, у которых в RSS найдено изображение. Если изображение не найдено или URL не отдаёт картинку, материал не публикуется.
- Если достойных новостей меньше пяти, очередь содержит только найденные материалы.

## Первый запуск

- Python 3.12+
- Установить зависимости из requirements.txt.
- Скопировать .env.example в /home/zendigest/.env и заполнить секреты.
- Указать числовой Telegram ID администратора в TELEGRAM_ADMIN_IDS.
- Добавить @privazen_bot администратором @zentestdigest с правом публикации.
- Запустить python main.py.

## Команды

- /start, /help — помощь.
- /status — состояние базы и сегодняшней очереди.
- /run — личный предпросмотр текстов, без публикации в канал.
- /prepare — подготовить очередь на сегодня.
- /publish — отправить следующий материал в тестовый канал.
- /myid — показать свой Telegram ID.

Команды управления доступны только TELEGRAM_ADMIN_IDS.

## Безопасность и тестирование

Начальная версия закреплена за @zentestdigest. @zentgrm не используется. Не коммитьте .env и секреты. Не запускайте более одного polling-процесса с тем же токеном. Служба systemd — отдельная, zendigest.service; другие службы не меняются. Логи HTTPX/HTTP Core не пишут INFO-запросы, содержащие Telegram Bot API URL с токеном.

## Источники

RSS-ленты Guardian, BBC, Pitchfork и тематические Google News RSS. Ошибки отдельных лент не останавливают сбор остальных. При сбое Gemini или Telegram выпуск не отмечается опубликованным.
